# AST Chem-Tooling — แค็ตตาล็อกสินค้า

เว็บไฟล์เดียว ไม่มีเซิร์ฟเวอร์ ไม่มีฐานข้อมูล ข้อมูลเก็บอยู่ในเบราว์เซอร์
ของเครื่องที่เปิดใช้ (localStorage)

**แอปนี้มีหน้าที่เดียว: โชว์ว่าร้านมีสินค้าอะไรบ้าง** ไม่มีตะกร้า ไม่มีเช็คเอาต์
ไม่มีบันทึกออเดอร์ ไม่มีสต๊อก — ของพวกนั้นย้ายไปอยู่ในชีทกับระบบคีย์ออเดอร์
(Apps Script ในโฟลเดอร์ `apps-script/`) ทั้งหมดแล้ว ลูกค้าเห็นสินค้าแล้วกดทักไลน์
พนักงานคีย์ออเดอร์ในระบบนั้นที่เดียว ยอดถึงจะเข้าชีทและตัดสต๊อกให้

## repo นี้เปิดสาธารณะ — อ่านก่อนแก้

ใครก็เปิดดูไฟล์ในนี้ได้ **ห้ามใส่ข้อมูลลูกค้าลงไฟล์ที่ commit ขึ้นมาเด็ดขาด**
(ชื่อ เบอร์โทร ที่อยู่ สลิปโอนเงิน ข้อมูลผู้เสียภาษี) และห้ามใส่รหัสเข้าหลังร้าน

## สองไฟล์ ใครใช้อะไร

| ไฟล์ | ใครเปิด | มีอะไร |
|---|---|---|
| `index.html` | ทุกคน — เปิดผ่าน GitHub Pages | แบนเนอร์ · หมวดหมู่ · สินค้า รูป ราคา · ปุ่มทักไลน์ |
| `admin.html` | ตัวจริงที่ใช้แก้โค้ด | เหมือนกันทุกอย่าง |

โหมดแก้ไขร้าน (ปุ่มเฟือง มีรหัสของเครื่องกั้น) มี 6 แท็บ:
**ข้อมูลร้าน · สินค้า · สินค้าแนะนำ · หมวดหมู่ · แบนเนอร์ · ไฟล์**
สินค้าแต่ละตัวมีสวิตช์ "มีของ / สินค้าหมด" อย่างเดียว จำนวนคงเหลือจริงดูที่ชีท

`index.html` ถูก**สร้างจาก** `admin.html` — แก้โค้ดที่ `admin.html` เท่านั้น แล้วสั่ง

```bash
python3 tools/build.py
```

`tools/build.py` จะ:

1. ล้าง `orders` `pin` `lots` `moves` ออกจาก `#DATA` ของทั้งสองไฟล์ (ปกติว่างอยู่แล้ว)
2. ล้างหน้าจอที่ติดมากับไฟล์ (ปุ่ม "ดาวน์โหลดไฟล์แอป" คัดลอกหน้าจอตอนนั้นทั้งดุ้น
   — เคยทำให้ชื่อและเบอร์ลูกค้า 18 รายหลุดขึ้น repo มาแล้ว)
3. สร้าง `index.html` จาก `admin.html`
4. **ตรวจซ้ำแล้วล้มทันทีถ้ายังเจอเบอร์โทรของคนอื่นหลงเหลืออยู่**

ทั้งสองไฟล์ที่ commit ขึ้นมาจึงไม่มีออเดอร์และไม่มีรหัสฝังอยู่เลย

## ข้อมูลจริงอยู่ที่ไหน

- **ในเครื่องพนักงาน** (localStorage ของเบราว์เซอร์นั้น) — คนละเครื่องคนละชุด ไม่ซิงก์กัน
- **ไฟล์สำรอง `.json`** ที่กดจากแท็บ "ไฟล์" ในหลังร้าน — เก็บไว้ในเครื่อง อย่าอัปขึ้นที่สาธารณะ

**ควรกดสำรองเป็นไฟล์ `.json` ไว้เป็นประจำ** ถ้าเครื่องพัง หรือเผลอล้างข้อมูลเบราว์เซอร์
ข้อมูลจะหายโดยไม่มีที่ให้กู้

## รหัสเข้าหลังร้าน

ไม่ได้ฝังอยู่ในไฟล์ เครื่องไหนเปิด `admin.html` ครั้งแรกจะให้ตั้งรหัสของเครื่องนั้นเอง
รหัสเก็บอยู่ในเครื่องนั้นเท่านั้น

> รหัสนี้กันคนที่กดมั่วเท่านั้น **ไม่ใช่ระบบความปลอดภัยจริง** เพราะแอปไม่มีเซิร์ฟเวอร์
> ความปลอดภัยจริงมาจากการที่ `admin.html` ไม่มีข้อมูลลูกค้าอยู่ในไฟล์ตั้งแต่แรก

| `tools/build.py` | สร้าง `index.html` จาก `admin.html` |
