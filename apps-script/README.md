# หลังบ้าน — Apps Script บนชีทของร้าน

โค้ดในโฟลเดอร์นี้ทำงานอยู่บน Google ไม่ใช่ในเครื่อง ข้อมูลทั้งหมดอยู่ในชีท
`AST_ระบบออเดอร์และสต๊อก3008` ไม่มีข้อมูลลูกค้าอยู่ในไฟล์เหล่านี้เลย

## กติกาข้อเดียวที่ห้ามลืม

ชีทของร้าน **ใส่สูตรรอไว้ทุกแถวแล้ว** ตั้งแต่แถว 6 ถึงแถว 501 (หัวบิล) และ 1201 (รายการ)
แถวที่ดูว่างเปล่าก็มีสูตรอยู่ มันแค่คืนค่าว่างเพราะยังไม่มีข้อมูลให้คำนวณ

> เขียนตัวเลขทับช่องสูตรเมื่อไร สูตรแถวนั้นหายถาวร
> ยอดสินค้า ต้นทุน กำไร VAT ของออเดอร์ใบนั้นจะค้างเป็นเลขนิ่ง ไม่อัปเดตอีกเลย และไม่มีอะไรฟ้อง

`Sheets.gs` จึงมีตาราง `SH` บอกว่าคอลัมน์ไหนกรอกได้ คอลัมน์ไหนเป็นสูตร
และ `writeRow_()` จะโยน error ทันทีถ้ามีโค้ดพยายามเขียนลงช่องสูตร

| ชีท | ช่องที่เขียนได้ | ช่องสูตร ห้ามแตะ |
|---|---|---|
| ออเดอร์_หัวบิล | A–I, K, L, Q, S, T | J, M, N, O, P, R, U |
| ออเดอร์_รายการ | B, D, G, I | A, C, E, F, H, J–P และ Q ที่เพิ่มใหม่ |

## ไฟล์

| ไฟล์ | ทำอะไร |
|---|---|
| `Sheets.gs` | รู้ว่าคอลัมน์ไหนอยู่ตรงไหน · อ่าน/เขียนแถวอย่างปลอดภัย · หาแถวว่าง |
| `Fefo.gs` | เลือกล็อตที่หมดอายุก่อนมาตัดก่อน — โค้ดล้วน ไม่แตะชีท ทดสอบด้วย node ได้ |
| `Setup.gs` | สร้างชีท `ล็อตสินค้า` · `ตัดล็อต` และเพิ่มคอลัมน์ Q ที่ `ออเดอร์_รายการ` |
| `Api.gs` | สิทธิ์เข้าใช้ · เสิร์ฟหน้าเว็บ · `createOrder()` บันทึกออเดอร์ |
| `Index.html` | หน้าจอคีย์ออเดอร์บนมือถือ |

## ติดตั้งครั้งแรก

1. เปิดชีท → เมนู **ส่วนขยาย › Apps Script**
2. เพิ่มไฟล์ตามรายการข้างบน (ไฟล์ `.gs` เลือกชนิด **สคริปต์** · `.html` เลือก **HTML**
   ตอนตั้งชื่อไม่ต้องพิมพ์นามสกุลต่อท้าย)
3. **การตั้งค่าโปรเจกต์** → ติ๊ก "แสดงไฟล์ appsscript.json" แล้ววางเนื้อหาจาก `appsscript.json` ทับ
4. เลือกฟังก์ชัน **`setup`** กด **Run** ครั้งเดียว แล้วอนุญาตสิทธิ์ตามที่ Google ถาม
   (สั่งซ้ำได้ ไม่ทำข้อมูลหาย · จะซ่อมสูตร `#REF!` ในชีทสต๊อกให้ด้วยถ้ามี)
5. **ทำให้ใช้งานได้ › การทำให้ใช้งานได้ใหม่ › เว็บแอป**
   - ทำงานในชื่อ: **ผู้ใช้ที่เข้าถึงเว็บแอป**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคนที่มีบัญชี Google**
6. ส่งลิงก์ที่ได้ให้พนักงาน — เปิดจากมือถือแล้วกด "เพิ่มลงหน้าจอโฮม" ได้เลย

## ใครเข้าระบบได้

**แชร์ชีทให้ใคร คนนั้นใช้แอปได้** — ไม่ต้องตั้งอะไรเพิ่ม ไม่ต้องรู้ว่าโดเมนบริษัท
เป็น Google Workspace หรือเปล่า

> เปิดชีท → กด **แชร์** → ใส่อีเมลพนักงาน → เลือก **ผู้แก้ไข**

เหตุผลที่ผูกกับการแชร์ชีท: คนที่แก้ชีทได้ ก็ทำทุกอย่างที่แอปทำได้อยู่แล้ว
การมีรายชื่อสองที่ให้ดูแลมีแต่จะหลุด

เอาคนออกก็ถอนสิทธิ์ในชีทตามปกติ (ระบบจำรายชื่อไว้ 5 นาที ถอนแล้วรออีกนิด)

ยังมีอีกสองทางสำรองที่ผ่านได้เหมือนกัน ใช้เมื่อจำเป็น:

| ทาง | ตั้งที่ไหน |
|---|---|
| อีเมลลงท้าย `@chem-inno-tech.com` | ค่า `ALLOW_DOMAIN` ใน `Api.gs` |
| รายชื่อเฉพาะราย | การตั้งค่าโปรเจกต์ › คุณสมบัติของสคริปต์ คีย์ `ALLOW_EMAILS` |

ด่านจริงอยู่ใน `requireStaff_()` ไม่ใช่ที่หน้าจอ — คนที่ไม่ผ่านทั้งสามทาง
ต่อให้รู้ลิงก์ก็เรียกฟังก์ชันไม่ได้ และถ้าระบบอ่านอีเมลไม่ออก จะปฏิเสธไว้ก่อนเสมอ

## ทดสอบก่อนแตะของจริง

```bash
node tools/t_fefo_unit.js                          # ตรรกะ FEFO
node tools/t_order_sheet.js                        # บันทึกออเดอร์บนชีทจำลอง
python3 tools/make_preview.py && node tools/t_ui.js # หน้าจอจริงในเบราว์เซอร์
```

`tools/fakesheet.js` จำลอง SpreadsheetApp มากพอที่จะรัน `Sheets.gs` กับ `Api.gs`
ได้ทั้งไฟล์ และ **จดไว้ทุกครั้งที่มีการเขียนทับช่องสูตร** — ข้อสอบที่สำคัญที่สุด
ของชุดทดสอบนี้คือรายการนั้นต้องว่างเปล่า

`tools/make_preview.py` ประกอบไฟล์ทั้งหมดเป็นหน้าเว็บไฟล์เดียวที่เปิดในเครื่องได้
พร้อม `google.script.run` จำลอง แล้ว `tools/t_ui.js` ขับด้วยเบราว์เซอร์จริง
ตั้งแต่วางข้อความจากไลน์จนพิมพ์ใบปะหน้าออกมาเป็นรูป

ข้อมูลในไฟล์ทดสอบทั้งหมดเป็นข้อมูลสมมติ **ห้ามเอาชื่อ เบอร์ หรือที่อยู่ลูกค้าจริง
มาใส่ในไฟล์ทดสอบ** — `tools/build.py` มีด่านตรวจเบอร์โทรไว้ให้แล้ว

## สิ่งที่ระบบกันไว้ให้แล้ว

- คนสองคนกดพร้อมกัน → `LockService` กันเลขออเดอร์ซ้ำ
- กดซ้ำ / เน็ตหลุดแล้วยิงใหม่ → `clientKey` ทำให้ได้ออเดอร์ใบเดิม ไม่ใช่ใบใหม่
- บันทึกล้มกลางทาง → ล้างแถวที่เพิ่งเขียนออกหมด ไม่ทิ้งออเดอร์ครึ่งใบ (และไม่ล้างสูตรทิ้ง)
- ยอดที่ชีทคำนวณไม่ตรงกับที่ควรเป็น → ยกเลิกทั้งใบ ดีกว่าปล่อยยอดผิดค้างไว้
- ชีทเต็ม (สูตรลากมาไม่ถึง) → บอกตรง ๆ ว่าเต็มและสูตรมีถึงแถวไหน
- ล็อตไม่พอ / ล็อตหมดอายุ → ไม่ตัดขาย บอกตัวเลขจริงว่าเหลือเท่าไร
